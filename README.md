# Secure Photo — Website

Public website for **Secure Photo**, a Face ID–protected, encrypted photo vault for iPhone and iPad.

| Page | |
|---|---|
| [`index.html`](index.html) | Overview and features |
| [`privacy.html`](privacy.html) | Privacy policy |
| [`support.html`](support.html) | Help and FAQ |

Plain HTML and one stylesheet (`assets/style.css`), no build step. Light and dark mode follow the visitor's system setting.

Serve with GitHub Pages (Settings › Pages › Deploy from branch `main`, folder `/`) or preview locally:

```bash
python3 -m http.server 8000
```

Support requests: [open an issue](https://github.com/giridharmb/SecurePhoto-Docs/issues).
